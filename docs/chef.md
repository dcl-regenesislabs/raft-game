# Italian Chef GLB Reference

Source asset: `assets/scene/items/italian_chef.glb`

This file documents the GLB structure so future edits to the chef factory
(`src/factories/chef.ts`) and any system that drives chef animations don't
have to re-introspect the binary.

## File facts

- glTF 2.0, generated by **Khronos glTF Blender I/O v4.2.57**
- Single root node: **`Armature`** (scene 0)
- 26 nodes total, 1 skin
- 1 mesh: **`char1`** (1 primitive)
- Uses extension: `KHR_materials_unlit`

## Skeleton

The chef rides on a standard Mixamo-style humanoid rig under `Armature`
(LeftToeBase / LeftFoot / LeftLeg / LeftUpLeg / Right* / Spine / Hips / etc.).
Bone units are **centimeters** baked into the GLB — the SDK scales the
GLB to its visual size via `Transform.scale`; we don't touch the bone
lengths.

## Animation clips (13)

All clips share the same skeleton. Index = the order they appear in the
glTF `animations` array.

**Important history:** the GLB was originally exported from Mixamo with
generic clip names (`Agree_Gesture`, `Chair_Sit_Idle_M`, `Idle_8`, …).
A walk-test through the debug cycler (`debugCycleAllClips: true` on
`createChef`) showed those labels **did not match the actual motions** —
e.g. the clip labeled `Agree_Gesture` was actually a seated idle. The
GLB has since been rewritten in place to give each clip a name that
describes what it visually does. Backup of the original is at
`assets/scene/items/italian_chef.glb.bak`.

All clip names are lowercase + underscore (snake_case) for consistency.

### Renaming the GLB animations

The GLB JSON chunk was patched in place with a Python script. If clip
names need to change again, the procedure is:

```bash
cp assets/scene/items/italian_chef.glb assets/scene/items/italian_chef.glb.bak
python3 <<'PY'
import json, struct
GLB = 'assets/scene/items/italian_chef.glb'
RENAMES = { 0: 'new_name_0', 2: 'new_name_2' }  # idx -> new name
with open(GLB, 'rb') as f: data = f.read()
magic, ver, _ = struct.unpack('<III', data[:12])
json_len = struct.unpack('<I', data[12:16])[0]
gltf = json.loads(data[20:20+json_len].decode('utf-8').rstrip(' \t\r\n\0'))
for i, n in RENAMES.items(): gltf['animations'][i]['name'] = n
after = data[20+json_len:]
new_json = json.dumps(gltf, separators=(',',':'), ensure_ascii=False).encode('utf-8')
pad = (4 - len(new_json) % 4) % 4
new_json += b' ' * pad
total = 12 + 8 + len(new_json) + len(after)
with open(GLB, 'wb') as f:
    f.write(struct.pack('<III', magic, ver, total))
    f.write(struct.pack('<I', len(new_json)) + b'JSON')
    f.write(new_json); f.write(after)
PY
```

Then update `CHEF_ALL_CLIPS` in `src/factories/chef.ts` and this table.

## SDK7 Animator pattern (important)

Use a **single-state** Animator listing only the clip you want to play.
Empirically — with this 13-clip GLB on the current renderer — the
multi-state variant (every clip enumerated, only one with `playing:
true`) caused the renderer to fall back to clip index 0
(`Agree_Gesture`) instead of the requested clip. Listing only the target
clip works because non-listed clips don't get sent to the renderer at
all, so there's no resolution ambiguity.

`createChef` wires this for you — pass `idleClip: '<clip name>'` to pick
the pose.

```ts
// Standing greeter (lobby)
createChef({ /* ... */ })                                // defaults to CHEF_IDLE_CLIP

// Seated chef on the boat
createChef({
  /* ... */
  idleClip: CHEF_SITTING_IDLE_CLIP   // 'Chair_Sit_Idle_M'
})
```

If you need to swap clips at runtime (e.g. a "cheer when player scores"
moment), follow the shark pattern in `src/systems/sharkDirector.ts`
(`startBite`/`stopBite`): flip `playing` flags on the relevant states and
set `shouldReset = true` on the newly-activated clip.

## Adding a new pose

1. Pick a clip name from the table above.
2. Export it as a constant in `src/factories/chef.ts` (e.g.
   `export const CHEF_BOW_CLIP = 'Formal_Bow'`).
3. Pass it via `idleClip` when calling `createChef`, or drive it at
   runtime via `Animator.getMutable(chef).states`.
If the chef GLB is replaced with a new export, re-run the introspection:

```bash
python3 -c "
import json, struct
data = open('assets/scene/items/italian_chef.glb','rb').read()
chunk_len = struct.unpack('<I', data[12:16])[0]
gltf = json.loads(data[20:20+chunk_len].decode('utf-8'))
for i, a in enumerate(gltf['animations']):
    print(f'{i:>3}  {a[\"name\"]}')
"
```

…and update this doc.
