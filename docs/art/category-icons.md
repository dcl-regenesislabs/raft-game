# Craft category artwork

Generated with the built-in image generation tool. Final full-resolution source images live in `images/concepts/categories/`; runtime RGBA icons live in `images/hud/categories/`. `scripts/build-category-icons.py` only downsizes the selected generated artwork to 128×128, preserving transparency. The manifest records generation provenance.

## Final prompt template

Simplify this game category icon while preserving the SAME illustrated survival-game item art style, soft shading, warm wooden materials, teal accents and rounded substantial forms. Subject: [subject below]. Reduce to the essential large readable shapes: remove grain, scratches, tiny fittings, excess rings, ornate details and redundant parts. Keep a little dimensionality and gentle broad shading. NOT a flat vector symbol, NOT a monochrome glyph, NOT photorealistic. Friendly handcrafted illustrated object consistent with existing game inventory items. Readable at 44 pixels. One centered compact composition filling 80 percent of square canvas; transparent background; no text, frame or scenery.

Each generation used the preceding category image as its style/edit reference.
